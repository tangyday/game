# 냥냥 팡!

고양이 캐릭터를 이용한 뿌요뿌요 스타일의 간단한 퍼즐 게임입니다.

## GitHub Pages에 올리는 방법
1. 새 GitHub 저장소를 만듭니다.
2. 이 ZIP 파일을 압축 해제합니다.
3. `index.html`, `README.md`, `.nojekyll` 파일을 저장소 최상위 폴더에 업로드합니다.
4. 저장소의 **Settings → Pages**로 이동합니다.
5. **Deploy from a branch**를 선택합니다.
6. `main` 브랜치와 `/ (root)`를 선택한 뒤 저장합니다.
7. 잠시 기다리면 GitHub Pages 주소에서 게임을 플레이할 수 있습니다.

## 조작법
- ← / → : 이동
- ↑ 또는 X : 회전
- ↓ : 빠르게 내리기
- Space : 즉시 내리기
- 모바일 : 화면 아래 버튼 또는 스와이프
